## Summary
The first large empirical study of prompt injection against agentic coding editors (Cursor, GitHub Copilot agent mode). Attackers poison development resources the agent reads, such as rules files or docs, and the agent then runs the attacker's terminal commands. The tool AIShellJack automates hundreds of payloads mapped to MITRE ATT&CK, and success rates for executing malicious commands reached 84%.

## Key points
- AIShellJack: 314 attack payloads covering 70 MITRE ATT&CK techniques.
- Targets: GitHub Copilot and Cursor, which have terminal access and dev-environment privileges.
- Attack success for malicious command execution as high as 84%.
- Objectives achieved range from initial access and discovery to credential theft and data exfiltration.

## Excerpts
> "attackers can remotely exploit these systems by poisoning external development resources with malicious instructions, effectively hijacking AI agents to run malicious commands, turning "your AI" into "attacker's shell"." (Abstract)

## Relevance to the talk
The coding-agent version of Greshake: repository content is the injection vector, and the payload is a shell command. Directly motivates OS-level sandboxing of the agent's terminal and egress control.
