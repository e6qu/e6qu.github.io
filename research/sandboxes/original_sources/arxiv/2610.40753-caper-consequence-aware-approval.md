## Summary
Automated approvers for coding-agent shell commands (rule checkers, guardrail models, permission classifiers) judge the *text* of a command, but what a command does depends on the code it invokes and workspace state. Caper pre-executes each command in a snapshotted sandbox, shows an independent approver a bounded report of the observed effects, commits allowed commands and rolls back blocked ones with a reason.

## Key points
- Pre-execute in snapshot, observe effects, then commit or roll back.
- Lowest harmful-outcome rate among seven systems on SABER (6.7% vs at least 14.8%).
- New benchmark YoloFS-Ext hides harm inside invoked tools: 7.8% vs at least 35.3%.
- Blocks only 1.0% of the safe twins of dangerous tasks.

## Relevance to the talk
Shows snapshots (an old VM feature) becoming a *policy* tool for agents: run it, look, then decide. Ties the microVM snapshot research to agent safety.
