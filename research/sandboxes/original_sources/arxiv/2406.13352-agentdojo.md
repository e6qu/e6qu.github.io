## Summary
AgentDojo is an extensible environment (not a fixed test set) for measuring both utility and security of agents that call tools over untrusted data: email, banking, travel, workspace suites. It became the de facto yardstick for later system-level defenses (CaMeL, Progent, f-secure and others report their numbers on it). Its headline finding is that both attacks and defenses are immature: models fail many tasks even without attacks, and attacks break some but not all security properties.

## Key points
- 97 realistic tasks, 629 security test cases; supports adaptive attacks and pluggable defenses.
- Measures utility under attack as well as attack success, exposing the security/utility trade-off.
- Open source: github.com/ethz-spylab/agentdojo.

## Excerpts
> "AI agents are vulnerable to prompt injection attacks where data returned by external tools hijacks the agent to execute malicious tasks." (Abstract)

> "AgentDojo is not a static test suite, but rather an extensible environment for designing and evaluating new agent tasks, defenses, and adaptive attacks." (Abstract)

## Relevance to the talk
The benchmark everyone uses; when a talk slide quotes "X% of tasks solved with provable security" it is usually an AgentDojo number. Note its scope: tool-API agents, not shell-wielding coding agents.
