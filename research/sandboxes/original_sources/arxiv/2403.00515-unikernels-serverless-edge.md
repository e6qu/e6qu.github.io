## Summary
Compares unikernels (Nanos, OSv) against Firecracker microVMs, Docker containers and gVisor as sandboxes for edge FaaS, on cold start, idle footprint and other metrics. Unikernels start fast but are less stable than Linux microVMs. The paper states the common view plainly: Docker alone is generally not considered enough for untrusted code, so commercial platforms use microVMs or hardened runtimes.

## Key points
- Compared: Nanos and OSv unikernels, Firecracker microVMs, Docker, gVisor.
- Metrics include cold-start overhead and idle footprint.
- Unikernels: desirable cold start, but behind Linux microVMs in stability.

## Excerpts
> "Although Docker containers are lightweight and popular in open-source FaaS platforms, they are generally considered insufficient for executing untrusted code and providing sandbox isolation." (Abstract)

> "Commercial cloud FaaS platforms thus rely on Linux microVMs or hardened container runtimes, which are secure but come with a higher resource footprint." (Abstract)

## Relevance to the talk
A compact side-by-side of the isolation options the talk covers, from a measurement paper rather than vendor material. The two quoted sentences summarise the industry consensus the agent-sandbox vendors inherited.
