## Summary
The paper describing OpenHands (formerly OpenDevin), an open platform for coding/web agents. Architecturally it is the canonical "agent outside, sandbox inside" design: the agent's commands, code and browser actions execute in a sandboxed runtime (a Docker container) separate from the host, with an event stream connecting the two. Evaluated across 15 benchmarks including SWE-bench and WebArena.

## Key points
- Platform supports implementing agents, "safe interaction with sandboxed environments for code execution", multi-agent coordination and evaluation.
- Agent acts like a developer: writes code, uses a command line, browses the web.
- Large open community (MIT licence, 2.1K+ contributions from 188+ contributors at time of writing).
- Note: OverEager-Bench (arXiv 2605.18583) later found OpenHands' ask-to-continue design had far fewer out-of-scope actions than more permissive CLIs.

## Excerpts
> "We describe how the platform allows for the implementation of new agents, safe interaction with sandboxed environments for code execution, coordination between multiple agents, and incorporation of evaluation benchmarks." (Abstract)

## Relevance to the talk
Reference architecture for container-per-agent coding sandboxes, the academic counterpart to hosted sandboxes like E2B/Modal/Daytona.
