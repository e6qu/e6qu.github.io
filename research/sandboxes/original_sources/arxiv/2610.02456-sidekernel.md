## Summary
A practicum project that starts from a user survey: fewer than 40% of AI coding agent users run their agents in a sandbox, mainly because of usability barriers. It builds SideKernel, an open-source local microVM sandbox for coding agents on macOS, and compares it against market alternatives on 23 capability tests derived from those barriers; Docker Sandboxes and SideKernel score highest on usability features.

## Key points
- Formative online survey: under 40% of respondents sandbox their coding agents.
- Design target is usability, not only isolation strength.
- Comparative analysis of local, open-source microVM sandboxes for macOS agents (secondary contribution: a survey of that solution space).
- Single-author student project; survey sample and methodology are limited.

## Excerpts
> "AI coding agents are untrusted system components, yet they require autonomy on the developer machines they run on. This contradiction is a security problem." (Abstract)

## Relevance to the talk
A rare (if small) adoption datapoint, and a reminder that the barrier is usability. Relevant to the macOS section (Virtualization.framework-based microVMs for agents).
