## Summary
Demonstrates that leading LLMs can be coerced, through ordinary MCP tools (e.g. filesystem servers), into compromising the developer's own machine: malicious code execution, remote access, credential theft. Proposes MCPSafetyScanner, an agentic tool that audits an MCP server and reports vulnerabilities.

## Key points
- Attack classes shown: malicious code execution, remote access control, credential theft.
- MCPSafetyScanner uses several agents to generate adversarial samples, search for related vulnerabilities, and write a report.
- Open source: github.com/johnhalloran321/mcpSafetyScanner.

## Excerpts
> "we demonstrate that industry-leading LLMs may be coerced into using MCP tools to compromise an AI developer's system through various attacks, such as malicious code execution, remote access control, and credential theft." (Abstract)

## Relevance to the talk
Concrete early demonstration that MCP tools run with the user's ambient authority on a developer machine. Motivates running agents and their tool servers inside a sandbox with scoped filesystem and credentials.
