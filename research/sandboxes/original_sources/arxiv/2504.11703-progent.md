## Summary
Progent enforces least privilege on tool calls. Privileges are symbolic rules over tool names and arguments, checked deterministically on every call. An LLM drafts the initial policy from the user's task and proposes updates as the run unfolds, but an SMT solver classifies each update: narrowing is applied automatically, expansion requires explicit approval, so the agent's action space can only shrink silently ("monotonic confinement").

## Key points
- Policy = symbolic rules over tool names and arguments; deterministic enforcement on every call.
- LLM-generated policies, updated during execution; SMT-checked narrowing vs expansion.
- Evaluated on AgentDojo and ASB with large reductions in attack success and preserved utility.
- Integrated with LangChain and OpenAI Agents SDK.

## Excerpts
> "Each proposed update is determined by an SMT solver to be either a narrowing (applied automatically) or an expansion (requiring explicit approval), ensuring that the agent's effective action space can only shrink without approval (monotonic confinement)." (Abstract)

## Relevance to the talk
Least privilege and reference-monitor ideas applied at the tool-call layer, the agent analogue of seccomp filters. "Monotonic confinement" is a nice phrase for a slide; compare with "From Approval to Abuse", which attacks exactly the expansion-approval step.
