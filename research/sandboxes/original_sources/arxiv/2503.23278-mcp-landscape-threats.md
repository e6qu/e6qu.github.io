## Summary
A systematic study of MCP's architecture and security. It defines the lifecycle of an MCP server (creation, deployment, operation, maintenance; 16 activities) and builds a threat taxonomy across four attacker types, with real-world case studies and per-phase safeguards. It is the standard citation for "MCP widens the agent's attack surface".

## Key points
- Lifecycle: 4 phases, 16 key activities.
- Threat taxonomy: malicious developers, external attackers, malicious users, security flaws; 16 threat scenarios.
- Case studies of concrete attack surfaces in MCP implementations; proposes safeguards per phase and threat category.

## Excerpts
> "we construct a comprehensive threat taxonomy that categorizes security and privacy risks across four major attacker types: malicious developers, external attackers, malicious users, and security flaws, encompassing 16 distinct threat scenarios." (Abstract)

## Relevance to the talk
MCP servers are third-party code and third-party text running next to the agent: both a supply-chain and a prompt-injection channel. Supports a slide on sandboxing tool servers, not just the agent's shell.
