## Summary
Argues that LLM app ecosystems (ChatGPT plugins and similar) repeat the mistakes of early computing platforms: third-party apps share one context with no isolation. IsolateGPT applies browser/mobile-OS style process isolation: each app runs in its own "spoke" with its own LLM instance and memory, and a trusted "hub" mediates every cross-app interaction with user consent. It blocks many cross-app attacks with no loss of functionality and under 30% overhead for most queries.

## Key points
- Hub: non-LLM operator + planner LLM + system memory; routes queries and mediates collaboration.
- Spokes: one per app, each with a dedicated LLM, operator and memory; spokes cannot talk directly.
- Inter-spoke communication goes through the hub operator with format checks and user screening; permissions can be permanent, session-scoped or one-time.
- Threat model: third-party apps untrusted; LLM and host assumed trustworthy.
- Overhead under 30% for three-quarters of tested queries.
