## Summary
v86 is a full-system x86 PC emulator for the browser: it emulates CPU and hardware (PIC, PIT, IDE, VGA, NE2000, virtio…) and translates guest machine code to WebAssembly modules at runtime. It boots real operating systems (Linux distributions, FreeBSD, 9front, Haiku, ReactOS, Windows-era systems) inside a tab. Unlike CheerpX it emulates hardware rather than syscalls, so it runs a whole guest kernel.

## Key points
- "Machine code is translated to WebAssembly modules at runtime in order to achieve decent performance."
- CPU around Pentium 4 level incl. SSE3; missing multicore and 64-bit extensions (and some protected-mode/FPU features).
- Devices include an NE2000 NIC and virtio filesystem/network/balloon; demos for Arch Linux, Buildroot, FreeBSD, 9front, Haiku, ReactOS, Android-x86, etc.
- No performance figures in the README.

## Relevance to the talk
The far end of "Linux in Wasm": a whole VM (guest kernel + emulated devices) inside the Wasm sandbox inside the browser sandbox — maximal compatibility for 32-bit x86, single core, at emulation cost. Useful as a demo that "Wasm can run anything" is technically true, and as a reminder that you pay for it in speed.
