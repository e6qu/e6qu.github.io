# Hacker News: sandboxing AI coding agents — raw thread index

Collected 2026-11-22 from the HN Algolia API (`hn.algolia.com/api/v1`). About 230 story
queries (plus ~35 Show HN queries and ~40 broad high-points queries) gave 19,108 unique
stories from 2022 on. A title filter (an AI/agent term plus a sandbox, security, incident or
parallelism term) cut that to ~3,800, and each title above 20 points was then read by hand.
Low-point items are kept when they are primary sources (vendor posts, CVE write-ups) or
Show HNs of agent sandboxes.

Format: `date · points · comments · HN thread · original link`. Points and comment
counts are as of 2026-11-22, and threads are listed newest first within each section.
**[note]** marks a thread with its own note in this folder (`hn-<id>-<slug>.md`).

Caveats: Algolia ranks by relevance and caps each query at 1,000 hits, so a thread whose
title uses none of the query words can be missing. The same story is often submitted
several times; usually only the main submission is listed. Some vendor primary sources got
almost no HN traction: Anthropic's "Making Claude Code more secure and autonomous with
sandboxing" got 4 points, and the Codex sandbox post 15. That gap is itself a finding: HN
upvotes incidents and DIY sandboxes far more than vendor sandbox documentation.
