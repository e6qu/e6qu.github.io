Original "Shabby Castaway" sprites and tiles copied unchanged from
[e6qu/regular-mario](https://github.com/e6qu/regular-mario): the castaway's run
cycle from its [public game](https://e6qu.github.io/regular-mario/) on 2026-10-09,
and the rest (castaway poses, the grumbler and snapper, crates, coin, pipes,
scenery, castle, pennant, smoke and burst) from its authored asset set at
51fc9e4 on 2026-11-22.

Only the authored set is used. The game's ROM-extracted graphics, and its costume
sprites modelled on other games' characters, are never copied here.

The source grids and palettes are in
[build-parody-asset-set.mjs](https://github.com/e6qu/regular-mario/blob/main/scripts/build-parody-asset-set.mjs).
